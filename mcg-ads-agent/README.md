# MCG Ads Agent

MC Group Ads Agent plugin for Claude Code / Cowork / Claude Desktop.

วิเคราะห์ผลโฆษณา TikTok Ads ของ MC Group — การใช้เงินเทียบผลตอบแทน (ROAS), โครงสร้างแคมเปญและแอดกรุ๊ป, สุขภาพการวัดผล (pixel), กลุ่มเป้าหมาย — แล้วเชื่อมกับออเดอร์และสต็อกที่ MC Group มีอยู่จริง เพื่อตอบคำถามว่า **"โฆษณาคุ้มไหม และควรทำอะไรต่อกับงบก้อนถัดไป"** ไม่ใช่แค่รายงานตัวเลข

## Skills

| Skill | ทำอะไร |
|---|---|
| `tiktok-ads-review` | ทบทวนผลโฆษณาครบวง: งบรายวัน · แคมเปญที่กินงบ · โครงสร้าง/สถานะ · pixel และ audience · เทียบกับออเดอร์ที่ยังไม่จัดส่ง |

## Setup

Plugin นี้ **ไม่ประกาศ MCP server ของตัวเอง** — ข้อมูลทั้งหมดมาจาก connector **MC E-Commerce & Ads** ที่มีอยู่แล้ว

ถ้ายังไม่เห็น connector นี้ ให้เพิ่มก่อนใช้งาน ไม่งั้น skill จะเรียก tool ไม่ได้และจะบอกผู้ใช้ตรง ๆ ว่าให้เพิ่ม connector (ไม่ตอบจากความจำแทน)

## ข้อจำกัดที่ skill จะบอกผู้ใช้เสมอเมื่อเกี่ยวข้อง

- **กำไร/กำไรขั้นต้น** — ไม่มี COGS ไปได้ไกลสุดแค่ ROAS
- **โฆษณา Shopee / Lazada** — ยังไม่มีข้อมูล มีแต่ TikTok Ads
- **ที่เชื่อม ad ↔ SKU** — ยังไม่มี จึงไม่รู้ว่าแอดตัวไหนผูกสินค้าตัวไหน
- **ROAS รายแคมเปญ** — มักไม่มีค่า ต้องอ่านค่าจริงและรายงาน "ไม่มีข้อมูล" ไม่ใช่ 0

## กฎที่ skill ยึด

- ห้ามเดาตัวเลข — ทุกตัวต้องมาจากผลการเรียก tool ในบทสนทนานั้น
- metric ที่หายไปจากผลลัพธ์ **ไม่ใช่ 0** — หมายถึงผู้ให้ข้อมูลไม่มีค่าให้ ณ จุดนั้น
- ทุกจำนวนมีหน่วย · ยอดรวมต้องเท่ากับผลบวกของแถวที่แสดง
- ตัวเลขกำไร/จุดคุ้มทุนต้องตีตราว่าเป็นการประมาณ และระบุว่าต้องยืนยันกับใคร
- ห้ามพิมพ์ชื่อ tool/field/ตารางในคำตอบที่ผู้ใช้เห็น
