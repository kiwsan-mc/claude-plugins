# ทดสอบปลั๊กอิน mcg-ads-agent

วิธีใช้: ติดตั้งปลั๊กอินและ connector **MC E-Commerce & Ads** ก่อน แล้วพิมพ์ prompt ทีละข้อในแชต
ใหม่ ข้อ 3 ขึ้นไปคือข้อที่คุ้มที่สุด เพราะทดสอบ **กฎ** ไม่ใช่แค่การเรียกเครื่องมือ

**ผ่าน** = ตอบตรงตามที่เขียนไว้ในคอลัมน์ "ต้องได้"
**ไม่ผ่าน** = ฝ่าฝืนข้อใดข้อหนึ่งในหัวข้อ "ห้ามเห็นเด็ดขาด" ด้านล่าง

---

## 2. Trigger — ไม่ควรเรียก skill (5 ข้อ)

| prompt | ต้องได้ |
|---|---|
| `ยอดขายรวมเดือนนี้เท่าไร` | ส่งต่อ `mcg-sales-agent` — **ห้ามประกอบยอดขายบริษัทจากออเดอร์ที่นี่** |
| `เป้ายอดขายเดือนนี้เทียบยอดจริง` | ส่งต่อ `mcg-target-agent` — ที่นี่ไม่มีข้อมูลเป้า |
| `สต็อกสินค้าเหลือเท่าไร` | ตอบได้ แต่ต้องไม่ยืมกฎโฆษณามาใช้ |
| `ผลโฆษณา Lazada เป็นยังไง` | บอกตรง ๆ ว่า **ยังไม่มีข้อมูล** — ห้ามเดา ห้ามประมาณ |
| `ช่วยร่างอีเมลรายงานโฆษณาให้ทีม` | ไม่ต้องเรียก skill นี้ (เป็นงานเขียน ไม่ใช่วิเคราะห์) |

## 3. กฎ — ข้อที่ต้องดูว่าทำตามไหม

### 3.1 สองนาฬิกาของยอดขาย

**prompt:** `เทียบยอดขายกับงบโฆษณาให้หน่อย`

**ต้องได้:** ยอดที่ใช้คู่กับงบโฆษณาต้องมาจากแหล่งที่แพลตฟอร์ม attribut ให้ (Shopee: direct/broad GMV · TikTok: ประมาณจาก ROAS × งบ และติดป้ายว่าประมาณ) พร้อมชื่อแหล่งและ as-of

**ไม่ผ่านถ้า:** เอาคลัง (day-1) มาหารกับงบโฆษณา (realtime) ในอัตราส่วนเดียว หรือไม่บอกว่าใช้แหล่งไหน

### 3.2 ค่าที่หายไป ≠ 0

**prompt:** `ROAS ของแคมเปญ TikTok เป็นเท่าไร` (ถามแบบเจาะระดับแคมเปญ)

**ต้องได้:** แคมเปญที่ไม่มีค่า → เขียน **"ไม่มีข้อมูล"**

**ไม่ผ่านถ้า:** เขียน `0` หรือ `0.00` หรือ `-` แทน "ไม่มีข้อมูล"

### 3.3 direct กับ broad ต้องไม่ปนกัน

**prompt:** `ยอดขายจากแอด Shopee เป็นเท่าไร`

**ต้องได้:** บอกว่าใช้ **direct** หรือ **broad** · ตัวเลขตัวเดียวที่ไม่กำกับ = ไม่ผ่าน

**ไม่ผ่านถ้า:** เอาสองตัวมาบวกกัน หรือรายงานตัวเลขเดียวโดยไม่บอกว่าเป็นตัวไหน

### 3.4 Double Day กับ payday ต้องแยก

**prompt:** `งบพุ่งช่วง 5-10 เพราะแคมเปญ 9.9 ใช่ไหม`

**ต้องได้:** อธิบายว่าวันที่ 5–10 ตรงกับวัน Double Day พอดี และต้อง**แยกวัด**ก่อนสรุป — ถ้าวัดโดยตัดวัน Double Day ออกแล้วยังสูง แปลว่าเป็นคลื่นเงินเดือนด้วย

**ไม่ผ่านถ้า:** สรุปว่าเป็นเพราะ 9.9 อย่างเดียวโดยไม่แยกวัด

### 3.5 สองช่องทางจังหวะไม่เหมือนกัน

**prompt:** `จังหวะการใช้จ่ายของ TikTok กับ Shopee เหมือนกันไหม`

**ต้องได้:** **ตรงกันที่ปลายเดือน (23–25)** แต่ **ต่างกันที่กลางเดือน** — Shopee มีจุดที่ 15 · TikTok วันที่ 15 ทรุด

**ไม่ผ่านถ้า:** ตอบว่า "เหมือนกัน" หรือ "ต่างกัน" แบบไม่บอกว่าตรง/ต่างตรงไหน หรือย้ายวันที่ของช่องทางหนึ่งไปอีกช่องทาง

### 3.6 ห้ามเดาสาเหตุที่ยังไม่รู้

**prompt:** `ทำไม TikTok ถึงพุ่งกลางเดือนต่างจาก Shopee`

**ต้องได้:** บอกว่าวัดได้ว่าต่าง แต่เหตุยังไม่รู้ · อาจบอกว่าสองสมมติฐาน (วันสร้างแคมเปญ · budget mode) ถูกตัดออกแล้ว

**ไม่ผ่านถ้า:** ยกเหตุผลที่ไม่มีหลักฐาน เช่น "เพราะ TikTok ตั้ง budget ไม่เหมือนกัน"

### 3.7 ช่วงแคมเปญ = รอบ ไม่ใช่วันเดียว

**prompt:** `ผลแคมเปญ 10.10 เป็นยังไง`

**ต้องได้:** ระบุว่าใช้ช่วงไหนของแคมเปญนั้น (มีช่วงโปรโมทนำและช่วงเก็บตก) และ **ห้ามเทียบกับวันปกติ**

**ไม่ผ่านถ้า:** ดูวันเดียวแล้วสรุป หรือเทียบกับวันธรรมดา

### 3.8 เทียบข้ามปีต้องบอกว่าทำไม่ได้

**prompt:** `10.10 ปีนี้เทียบ 10.10 ปีก่อน`

**ต้องได้:** บอกตรง ๆ ว่า **ข้อมูลไม่ย้อนถึง เทียบไม่ได้**

**ไม่ผ่านถ้า:** ประมาณแล้วบอกว่าเป็นการประมาณ · หรือเงียบแล้วเทียบให้

### 3.9 หา payday เองจากข้อมูล

**prompt:** `ช่วยหารอบแคมเปญของร้านเราจากข้อมูล`

**ต้องได้:** ทำตามวิธี 6 ขั้น — แบ่งหน้าต่าง → จัดกลุ่มตามวันของเดือน → **มัธยฐาน** → เกณฑ์ 1.3 เท่า → **ตัดวัน Double Day ออกแล้ววัดซ้ำ** → ยืนยันด้วยชื่อแคมเปญ · และระบุจำนวนรอบที่เห็น

**ไม่ผ่านถ้า:** ตอบจากวันที่ที่จำมาโดยไม่ดึงข้อมูล · หรือใช้ค่าเฉลี่ยแทนมัธยฐาน · หรือไม่ทำขั้นตัด Double Day ซ้ำ

### 3.10 วันที่ต้องไม่ยืนยันเกินข้อมูล

**prompt:** `วันจ่ายเงินเดือนของร้านนี้คือวันที่เท่าไร`

**ต้องได้:** พูดแบบที่วัดได้ — *"งบพุ่งซ้ำที่วันที่ X ใน N รอบที่ดูมา"*

**ไม่ผ่านถ้า:** ยืนยันว่า "วันจ่ายเงินเดือนคือวันที่ 25" (ข้อมูลบอกไม่ได้)

### 3.11 หน่วยครบ

**prompt:** `สรุปภาพรวมโฆษณา Shopee ให้หน่อย`

**ต้องได้:** เงินมีสกุล (บาท) · ROAS/ROI บอกว่าเป็นเท่า · % มีเครื่องหมาย % · ออเดอร์บอกว่าเป็นออเดอร์

**ไม่ผ่านถ้า:** ตัวเลขจำนวนลอย ๆ ไม่มีหน่วย

## 4. ความสามารถของเครื่องมือ (ผลงาน ไม่ใช่กฎ)

| prompt | ต้องเห็น |
|---|---|
| `ยอดคงเหลือบัญชีโฆษณาเหลือเท่าไร` | ยอดคงเหลือ Shopee เป็นบาท — **ต้องอ่านก่อนตัวเลขอื่น** |
| `เมื่อวานนี้โฆษณาเผางบช่วงกี่โมง` | แถวรายชั่วโมงของวันนั้น พร้อมช่วงที่พุ่งสุด |
| `แคมเปญตัวไหนใช้เงินเยอะสุด` | ต้องมี **ชื่อแคมเปญ** ไม่ใช่แค่รหัส |
| `ควรยิงแอดสินค้าตัวไหนต่อ` | สินค้าที่แนะนำ + คำค้นพร้อมปริมาณการค้นหาและราคาเสนอ + ช่วงเป้าผลตอบแทน |
| `โฆษณาเพิ่มออเดอร์จนคลังรับไม่ไหวไหม` | ออเดอร์ที่ยังไม่เริ่มจัดเทียบงบ และ **ต้องกำกับว่าเป็นความสัมพันธ์ ไม่ใช่หลักฐานว่าแอดสร้างออเดอร์** |
| `TikTok มียอดขายจากโฆษณาไหม` | แยกให้ได้ว่า **แคมเปญ GMV Max มี GMV ของตัวเอง** ส่วนแคมเปญอื่นยังต้องประมาณจาก ROAS × งบ และติดป้ายว่าประมาณ |
| `ยอดคงเหลือบัญชีโฆษณา TikTok เหลือเท่าไร` | ตอบว่า **ดูไม่ได้** — 🚫 ห้ามตอบ 0 และห้ามใช้ตัวเลขจาก `get_advertiser` แทน |
| `pixel ยังยิง event อยู่ไหม` | ตอบได้ว่า pixel ยัง **ส่ง event เข้ามา** หรือหยุด — ต่างจากคำถามว่า "มี pixel ไหม" |

## 5. ห้ามเห็นเด็ดขาด (ใช้ตัดสินทุกข้อ)

- 🚫 ชื่อ tool · ชื่อ field · ชื่อตาราง · ชื่อระบบ (เช่น ชื่อ endpoint หรือคำอย่าง `onsite_shopping_roas`, `wms_status`) ในคำตอบที่ผู้ใช้เห็น
- 🚫 ตัวเลขยอดขายลอย ๆ ที่ไม่บอกว่าแหล่งไหน
- 🚫 เลข `0` ที่ใช้แทน "ไม่มีข้อมูล"
- 🚫 ตัวเลขกำไรหรือจุดคุ้มทุนที่รายงานเป็นข้อเท็จจริงโดยไม่ติดป้ายว่าเป็นการประมาณ
- 🚫 การเดาสาเหตุที่ยังไม่รู้
